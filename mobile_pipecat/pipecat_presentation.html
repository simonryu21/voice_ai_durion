💡 왜 Soniox인가?

  • ✅ 최고 정확도 - 벤치마크 테스트에서 대부분의 언어에서 1위
  • ✅ 혼합 언어 지원 - 한국어와 영어가 섞인 대화도 자연스럽게 인식
  • ✅ 실시간 처리 - WebSocket 기반 초저지연 스트리밍
  • ✅ 다양한 환경 - 다양한 음향 조건, 발화 스타일, 악센트에서도 높은 정확도

트랜스포트 옵션

트랜스포트 특징 용도
SmallWebRTC 로컬 WebRTC 서버, 간단한 설정 개발/테스트
Daily 클라우드 기반, 확장성 높음 프로덕션
WebSocket 양방향 통신, 실시간 데이터 커스텀 클라이언트
Twilio/Telnyx 전화 통화 지원 전화 기반 서비스

코드 예시

기본 파이프라인 구성

from pipecat.pipeline.pipeline import Pipeline from pipecat.services.google.stt import GoogleSTTService # 또는 다른 STT 서비스: # from pipecat.services.soniox.stt import SonioxSTTService # 최고 정확도 # from pipecat.services.deepgram.stt import DeepgramSTTService from pipecat.services.openai.llm import OpenAILLMService from pipecat.services.cartesia.tts import CartesiaTTSService # 서비스 초기화 stt = GoogleSTTService(...) # stt = SonioxSTTService(...) # Soniox: 최고 정확도, 혼합 언어 지원 llm = OpenAILLMService(...) tts = CartesiaTTSService(...) # 파이프라인 구성 pipeline = Pipeline([ stt, # 음성 → 텍스트 llm, # 텍스트 → AI 응답 tts # 텍스트 → 음성 ]) # 실행 runner = PipelineRunner(pipeline) await runner.run()
