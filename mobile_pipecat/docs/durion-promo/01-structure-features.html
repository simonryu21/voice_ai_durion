말하면 화면이 열립니다.

DuriOn은 앱을 여는 데서 멈추지 않고, 사용자가 하려던 행동의 마지막 상태까지 데려다주는 음성 AI입니다. Pipecat 실시간 파이프라인 위에서 STT·LLM·TTS를 오케스트레이션하고, 사용자 폰의 앱을 직접 실행합니다.

01 · Positioning

차별화는 "어디까지 데려가는가"

경쟁의 진짜 축은 "음성으로 답할 수 있느냐"가 아니라 앱 안의 어느 깊이까지 사용자를 데려가느냐입니다.

02 · Architecture

4개의 층이 하나처럼 움직입니다

스마트폰 화면부터 음성 두뇌까지 네 개의 층으로 나뉘어 있지만, 하나의 대화가 끊기지 않고 처음부터 끝까지 이어집니다. 말을 시작한 순간부터 앱을 다녀오는 순간까지 맥락이 그대로 유지됩니다.

2-Tier LLM

Supervisor는 "텍스트 vs 앱" 라우팅만, AppConcierge는 앱 선택·파라미터 추출에 집중 → 파라미터 정확도 ↑.

Personalized Routing

사용자 폰 인벤토리 + 큐레이션 카탈로그를 머지해 "내 폰에 있는 앱"만 후보로. 로그인 시 동적 system prompt 주입.

Lifecycle Tracking

handoff_id로 requested → opened → returned 전 구간 추적. 실패·복귀 이벤트는 즉시 LLM 컨텍스트로 주입.

05 · Strengths

경쟁사가 못 따라오는 3가지 특장점

01

앱 안 마지막 상태까지

앱마다 실행 방식이 제각각인 표준화의 벽을 넘어, "상위 30개 앱"을 정확히 큐레이션해 입력값까지 세팅된 화면으로 데려다줍니다.

✓ App 카탈로그 큐레이션 노하우 보유
02

내 폰에 맞춘 개인화

"지도 켜줘" 한마디에도 사용자마다 폰에 실제 설치된 앱으로 다르게 실행. 설치 앱을 학습해 나에게 맞는 앱만 후보로 올립니다.

✓ App Inventory 기반 개인화 라우팅
03

하나에 다 담긴 음성 비서

앱 실행부터 회의·번역·동시통역·오늘 할일(PLAN)까지 하나의 음성 대화로. 앱을 갈아탈 필요 없이 DuriOn 하나면 됩니다.
