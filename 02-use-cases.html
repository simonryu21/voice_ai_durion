Hero Scenario

운전 중 30초 · 3개 앱 연속 핸드오프 실행

🚗 운전 중
상황

거래처 전화로 미팅 장소가 갑자기 바뀐 외근 길. 갓길에 세울 시간도 없고, 핸들에서 손을 뗄 수도 없다. 머릿속엔 할 일 3가지.

"목적지를 OO건설 본사로 바꾸고, 김 팀장한테 10분 늦는다고 카톡으로 알려줘. 그리고 BTS 최신곡 틀어줘."

Killer Scenarios

상태 수준에서 끝내는 6가지 순간

공통점 — 앱을 여는 게 아니라 앱 안의 특정 상태까지 진입. 사용자는 마지막 1 액션만 하면 끝.

💬
Messaging · Deeplink
메신저 — 손 안 대고 전송 직전까지
"엄마한테 나 10분 늦는다고 카톡 보내줘"
→
엄마 채팅방 진입 + "10분 늦어요" 입력 완료 상태. Lv.1(앱만 열림)이면 엄마 검색·타이핑을 다시 해야 하지만, DuriOn은 「전송」만 남긴다.
대상+내용가드레일: 전송
💳
Payment · Vision Track
결제·송금 — 다녀오면 결과까지 인식
"Sarah한테 PayPal로 $50 보내줘"
→
보안·규제로 deeplink가 막힌 영역. 외부 결제 사이트로 핸드오프 → 결제 후 「Back to AI」로 복귀하면 화면을 Vision LLM이 읽어 "$50 송금 완료됐네요" 로 대화를 이어감.
외부 핸드오프Vision 복귀 분석
🧑‍💼
Meeting Agent
회의 — 받아쓰고, 요약하고, 정리
"회의 시작할게. 기록해줘"
→
홈 카드 「회의」로 진입 → 발화를 실시간 받아쓰고, 끝나면 안건·결정사항·액션아이템을 자동 요약. "누가 무엇을 언제까지"를 놓치지 않는다.
실시간 STT요약 · 액션아이템
🎧
Live Interpretation
동시통역 — 해외 미팅 실시간 양방향
"이제부터 동시통역 켜줘"
→
Live 오디오로 저지연 양방향 통역. 웹 챗봇은 마이크를 놓고 네이티브 앱이 단독 점유 → 끊김 없는 대화. 통역 종료 시 챗봇으로 자동 복귀.
LiveNative Audio
🌐
Translation Agent
번역 — 외국어 대화·문서 실시간
"이 문장 영어로 번역해줘"
→
봇 내 웹 번역 파이프라인으로 즉시 번역. 동시통역이 "실시간 회화"라면, 번역 Agent는 정확한 문장 단위 번역에 특화. 요청 단위로 web/native 분기.
웹 번역 파이프라인문장 단위

Memory · mem0
기억 — 매번 처음부터 설명 안 해도
"나 우유 알레르기 있는 거 기억하지? 근처 디저트 카페 찾아서 길안내해줘"
→
mem0가 개인 제약을 기억 → 조건 반영 검색 → 지도 앱 경로 안내 상태까지. 기억 + 검색 + 앱 실행이 한 발화에 묶인다.

DuriOn 가치를 빛낼 사용자 질의 시나리오 10선

텍스트로 답하면 손해인 발화만 골랐습니다. 손·눈이 바쁜 순간, 멀티스텝, 개인화, 앱 복귀 연속성 — DuriOn의 진가가 드러나는 한마디들.

1
"강남역까지 차로 가는 길 띄워줘"
길을 읽어주는 대신 티맵·네이버지도를 경로 안내 시작 상태로 실행. 운전 중처럼 화면 조작이 어려운 상황에서 가치 극대화.
Navigation
2
"엄마한테 '오늘 늦어' 카톡 보내려고"
카카오톡을 엄마 채팅방 + 메시지 입력 완료 상태로. 손이 바쁜 상황에서 앱 진입 단계를 음성으로 점프.
Messaging
3
"지도 켜줘" (모호한 발화)
네이버지도·티맵 둘 다 있으면 "어느 걸로 열까요?" 음성 재질의. 개인 인벤토리 기반 후보 선택의 똑똑함.
Disambiguation
4
(길찾기 앱 다녀온 뒤) "길 잘 찾으셨어요?"
앱을 떠났다 돌아와도 맥락이 끊기지 않음. "도착 예상시간 알림 걸어둘까요?"로 자연스럽게 이어감.
Return Continuity
5
"토스로 김대리한테 3만원 보내고 올게"
송금 앱 복귀 후 화면을 읽어 "송금 마치셨네요. 영수증 캡처해둘까요?" 행동 → 복귀 → 후속 제안 루프.
Payment · Vision
6
"어제 안 읽은 메일 중 중요한 것만 요약해줘"
Gmail·Outlook·네이버 메일을 가로질러 핵심만 음성 브리핑. 여러 계정을 한 번에.
Mail Summary
7
"방금 받은 회의 초대 메일, 일정에 넣어줘"
메일 요약 + 캘린더 앱 실행을 한 흐름으로 묶는 멀티스텝. PLAN과 자연스럽게 연결.
Mail → Calendar
8
"저번에 말한 그 추천 카페 다시 알려줘"
이전 세션 대화를 mem0가 기억해 맥락 복원. 매번 처음부터 설명할 필요 없음.
Memory
9
"나 우유 알레르기 있는 거 기억하지? 근처 디저트 카페 찾아 길안내해줘"
개인 제약(기억) + 검색 + 앱 실행을 한 발화에 결합. DuriOn의 결합력을 보여주는 복합 시나리오.
Memory + Search + Exec
10
"운전 중인데, 집 도착하면 보일러 켜지게 하고 가는 길에 주유소 띄워줘"
음성만으로 여러 앱·조건을 한 발화에. 손·눈을 못 쓰는 상황이야말로 음성 AI의 본질적 가치.
