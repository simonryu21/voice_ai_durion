◉ Main Use Cases

Finish speaking. Your next action is ready to go.

DuriOn is designed for moments when your hands and eyes are busy. These scenarios show how voice requests can prepare the next step inside an app.

Hero Scenario

On the road · Three app handoffs in one session

🚗 On the road
Situation

A client changes the meeting location while you are traveling. You have three tasks to prepare without working through each app manually.

“Change my destination to the client’s headquarters, tell Manager Kim on KakaoTalk that I’ll be 10 minutes late, and play the latest BTS track for me.”

1
T
TMap
Route guidance opens with the client’s headquarters as the destination. The scenario continues beyond the app’s home screen.
Remaining actions · None in this scenario
2

KakaoTalk
Manager Kim’s chat opens with “I expect to be about 10 minutes late” prepared for review. The user confirms Send when safely stopped.
Remaining action · Send

the latest BTS track Playback starts automatically without another request to choose the music.

Killer Scenarios

Six moments with the next step prepared

Each scenario prepares a specific state inside the app so the user can complete the final action.

💬
Messaging · Deeplink
Messaging — Prepare the message before sending
“Tell Mom on KakaoTalk that I’ll be 10 minutes late today.”
→
Mom’s chat opens with “I’ll be 10 minutes late” prepared for review. A basic launcher would still require finding Mom and typing; DuriOn leaves the final Send action to the user.
Recipient + message User confirms Send
💳
Payment · Vision Track
Payments — Continue after the external flow
“Send Sarah $50 through PayPal.”
→
Where security or policy restricts deep links, hand off to the external payment flow. After the user completes it and selects “Back to AI”, a vision LLM reads the screen and responds: “The $50 transfer is complete.” The conversation continues in context.
External handoff Vision analysis on return
🧑‍💼
Meeting Agent
Meetings — Transcribe, summarize and organize
“I’m starting a meeting. Please take notes for me.”
→
Open the Meeting card for a live transcript. At the end, summarize topics, decisions and action items including who owns each action and when it is due.
Live STT Summary · Action items
🎧
Live Interpretation
Interpretation — Two-way international conversations
“Turn on live interpretation now.”
→
Live audio enables low-latency, two-way interpretation . The web chatbot releases the microphone while the native app takes over, then resumes when interpretation ends.
LiveNative Audio
🌐
Translation Agent
Translation — Conversations and documents
“Please translate this sentence into English.”
→
The web translation pipeline handles the request immediately. While interpretation supports live conversation, the Translation Agent focuses on accurate sentence-level translation and routes each request to the appropriate web or native flow.
Web translation pipeline Sentence-level translation
🧠
Memory · mem0
Memory — No need to explain everything again
“Remember that I have a milk allergy ? Find a nearby dessert cafe and give me directions.”
→
mem0 recalls personal constraints, search applies them, and the map app opens with route guidance ready . Memory, search and app execution work together in one request.
Personal memory Search + app action
📅
